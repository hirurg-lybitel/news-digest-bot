# Privacy

This project publishes **public news headlines and summaries** to a Telegram channel.

## What we process

- Public RSS items (title, link, short snippet, publish time, source name)
- OpenAI API responses used to rank and summarize those items
- Telegram Bot API payloads needed to post into a channel you control

## What we do not intentionally collect

- End-user personal profiles from channel subscribers
- Private messages content for analytics (the posting bot is designed for channel publishing)
- Tracking cookies or advertising IDs

## Operator responsibility

If you run a public channel, you are the data controller for that channel under applicable law. Add your own privacy note in the channel description if you collect anything beyond automated public digests.

## Third parties

- [OpenAI](https://openai.com/policies/privacy-policy) — summarization
- [Telegram](https://telegram.org/privacy) — delivery
- News publishers — original articles (linked, not republished in full)

Summaries are transformative short digests; readers should open the original link for the full story.
