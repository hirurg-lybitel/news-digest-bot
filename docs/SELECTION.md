# Как выбираются главные новости

Пайплайн отбора — **детерминированная предобработка + AI-кластеризация событий + пакетная генерация текстов**. Нет ручной модерации.

## 1. Сбор (RSS)

Источники заданы в `src/sources.ts` (BBC, AP, CNN, NPR, NYT, Guardian, DW, Euronews, Al Jazeera).

Для каждого фида:
- заголовок, ссылка, краткий текст (snippet), время публикации;
- HTML в тексте убирается;
- сбой одного источника не останавливает остальные.

## 2. Фильтр свежести

Не фиксированные 24 часа — **с момента последнего успешного дайджеста**.

- Timestamp в `miniapp/data/state.json` (`lastDigestAt`)
- Первый запуск: `DEFAULT_LOOKBACK_HOURS` (по умолчанию **12**)
- Пропущенный cron: потолок `MAX_LOOKBACK_HOURS` (по умолчанию **24**)
- Расписание: **06:17 UTC** и **18:17 UTC** (09:17 и 21:17 Минск)

Новость попадает в пул, если `publishedAt >= since`. Записи без корректной даты отбрасываются: иначе старые элементы некоторых RSS постоянно возвращаются в каждый дайджест.
## 3. Дедупликация

- ключ: нормализованный URL (без `#fragment`, lower case);
- один URL = одна запись;
- порядок: по дате публикации (новые выше).

## 4. Кандидаты для AI

В модель уходит **до 80** самых свежих уникальных новостей (не весь пул).

Это ограничение по токенам и шуму: AI видит актуальный срез, а не сотни однотипных заголовков.

## 5. Кластеризация и ранжирование (OpenAI)

Один компактный запрос (`src/eventSelection.ts`) получает до 80 кандидатов и возвращает полный набор событий:
- `representativeIndex` — лучшая статья о событии;
- `memberIndices` — все публикации-дубликаты;
- `score` — важность 0–100;
- каноническая категория и краткое редакционное обоснование.

Код проверяет индексы, обеспечивает полное покрытие каталога и сортирует кластеры по `score`. Берётся до `MINI_APP_TOP_N` событий (по умолчанию **30**): **первые 10** → Telegram, **все** → Mini App. Слишком длинный ответ не отбрасывается целиком.

**Приоритет:**
- крупная геополитика и конфликты;
- стихийные бедствия, массовые жертвы;
- экономика с широким эффектом;
- наука / медицина (прорывы, регуляторные решения);
- landmark court / policy decisions.

**Пониженный приоритет:**
- celebrity gossip;
- мелкий спорт;
- повторяющиеся инкрементальные апдейты одной темы.

**Дедуп на уровне смысла (жёстко):** одно реальное событие (катастрофа, конфликт, решение суда и т.д.) → один кластер, даже если агентства дают разные форматы — breaking, explainer, science background, видео, live, «что вызвало X». Ссылка берётся из `representativeIndex`.

## 5a. Тексты RU/EN

После фиксации рейтинга `src/storyGeneration.ts` генерирует заголовки и короткие саммари пакетами по 10. Модель работает только с выбранными событиями и не может менять состав или порядок.

`link`, `source` и локализованные категории код подставляет сам из каталога — модель их не генерирует. При неполном ответе повторяются только отсутствующие элементы, а не весь дорогой каталог.

## 5b. Телеметрия AI

Каждый прогон пишет JSON в `miniapp/data/telemetry/`:
- `latest.json` — последний запуск
- `{utcArchiveKey}.json` — архив рядом с дайджестом

В файле:
- входной каталог и валидированные кластеры (`members`, представитель, score, rationale);
- каждый AI-вызов: этап, попытка, latency, `finishReason`, токены, ориентировочная стоимость и ошибки;
- `cost.estimatedTotalUsd` — итоговая стоимость AI за прогон;
- `snapshot.miniApp` — финальный список Mini App;
- `snapshot.telegram` — первые 10 историй и SHA-256 хэши RU/EN-постов (без дублирования полного текста).

Стоимость рассчитывается из фактического `usage` ответа OpenAI и ставок `OPENAI_INPUT_USD_PER_MILLION` / `OPENAI_OUTPUT_USD_PER_MILLION`. Это оценка: при изменении тарифа ставки нужно обновить.

Коммитится вместе с `miniapp/data/` в том же job.

## 6. Языковые версии

Для **одного и того же набора** историй генерируются:
- `title_ru`, `summary_ru`, `category_ru` — полностью на русском (заголовок переводится);
- `title_en`, `summary_en`, `category_en` — на английском.

Оба канала получают **одинаковый список событий**, различается только язык текста.

## 7. Публикация

Каждый настроенный канал (`TELEGRAM_CHANNEL_ID_RU`, `TELEGRAM_CHANNEL_ID_EN`) получает свой локализованный пост с **первыми 10** историями (или меньше, если в пуле меньше 10). В Mini App (`digest.json`) — **весь** отобранный список: те же новости, что в Telegram, плюс дополнительные до лимита `MINI_APP_TOP_N`.

---

## Что это **не** делает

- не считает «важность» по числу упоминаний в соцсетях;
- не использует ML-ранжирование кроме LLM;
- не гарантирует отсутствие ошибок перевода — нужна периодическая выборочная проверка.

## Настройка чувствительности

| Переменная | Эффект |
|------------|--------|
| `DIGEST_TOP_N` | сколько новостей в посте Telegram |
| `MINI_APP_TOP_N` | верхняя граница числа новостей в Mini App |
| `DEFAULT_LOOKBACK_HOURS` | окно при первом запуске |
| `MAX_LOOKBACK_HOURS` | потолок при пропуске cron |
| `OPENAI_MODEL` | качество отбора и формулировок |
Критерии отбора задаются в `src/eventSelection.ts`; формат текстов — в `src/storyGeneration.ts`.
